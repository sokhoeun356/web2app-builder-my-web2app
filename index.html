x1One AI Web2App Builder

Turns a website into an installable Android APK using the GitHub Actions workflow in this repository.

Deployed & running

Build an APK

  1. Open the Actions tab of this repository.
  2. Select x1One Ai Web2app - Build APK and choose Run workflow.
  3. Enter the website URL to wrap.
  4. Download the x1One-Web2App-APK artifact when the run finishes.
This page is served by the deployed container from branch appjet.
